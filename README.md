# Introduction
This is a guide for writing beautiful, workable, and consistent code.
Code style has a profound impact on the degree of difficulty in changing any given piece of code, and tends to be indicative of the overall quality of the software.
If the authors didn't take care in crafting the code, there may be larger structural issues that make changes difficult, as well as a greater potential for bugs and other software defects.
Pretty code does not guarantee fewer defects, but it generally makes them easier to fix.
In this document you will find practical principles, recipes, and examples to help you write some of the best code anywhere.

# General principles
I'll probably delete a bunch of this 😎

The number one goal is to make life easy for ourselves. When you need to fix something long after it was originally written, do you want to be greeted with a hard puzzle or an easy puzzle?
Unless you hate yourself or have a weird ego, you want an easy puzzle. Writing hard puzzles for yourself is dumb. Any idiot can write unintelligible, poorly structured code, and many do.
Writing easy puzzles is smart. It can take more work upfront, but this usually pays off in the long run.

Don't code against yourself. Do you need to check for errors that only exist if you write something which produces that error? No.

Be consistent.

Be concise.

Favor clarity over efficiency.

Deleting code is awesome.

Use language conventions for brackets and tabs-vs-spaces.

Don't let desperation cause you to sacrifice style. You're pinched for time and you just want it to work. You write something which, while it looks like garbage, does work. You ship the code.
Repeat this over a few years, and now your code is awful. Instead, take a minute to style the code properly. It isn't difficult and takes only a little bit of time, which will pay off later.
Get in the habit of writing pretty code and then do it every time.

Use whitespace properly. Somehow I'm always working on projects with tons of trailing whitespace and all kinds of whacked out spacing of things.
